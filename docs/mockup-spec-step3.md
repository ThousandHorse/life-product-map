# LifeProductMap – Step 3 UI モックアップ仕様書

> ChatGPT へのモックアップ依頼用ドキュメント。  
> このファイルを渡してレイアウト・デザインのモックアップを作成してもらう。

---

## アプリ概要

**LifeProductMap** は個人向け生産性アプリ。2 つのモードを持つ。

| モード | 用途 |
|---|---|
| 目標モード | 年目標 → 月マイルストーン → 週タスクの管理 |
| 勤怠モード | 出退勤打刻・稼働時間管理 |

---

## 画面全体のレイアウト構造

画面は **4 ペイン構成**（横並び）。

```
┌──────────────────────────────────────────────────────────────────┐
│  Pane 1 (NavPane)  │  Pane 2  │  Pane 3  │  Pane 4              │
│  240px             │  280px   │  flex-1  │  320px               │
│  ナビゲーション     │ タスク   │  詳細    │  AIチャット          │
│  （折りたたみ可）   │ 一覧     │          │ ※勤怠モード時は非表示│
└──────────────────────────────────────────────────────────────────┘
```

- 画面全体は `height: 100vh`、横スクロールなし
- Pane 1 は折りたたみ可能（アイコン幅 48px ↔ 展開幅 240px）
- Pane 4 は **勤怠モード時は非表示**

## Pane 1: NavPane（Step 3 の実装対象）

### 展開状態のレイアウト

```
┌────────────────────────┐
│ LifeProductMap    [◀] │  ← アプリ名 + 折りたたみボタン（高さ 48px）
├────────────────────────┤
│ モード                  │  ← セクションラベル（小文字・グレー）
│  🎯 目標     ← アクティブ │  ← 選択中は背景色あり
│  🕐 勤怠                │
├────────────────────────┤
│ 年目標           [+]  │  ← セクションラベル + 追加ボタン
│  ▶ TOEIC 900点取得     │  ← 目標行（クリックで選択）
│  ▶ 副業月収10万円      │
│  ▶ 体重65kg以下        │
│     ⋮ （最大5件）       │
└────────────────────────┘
```

### 折りたたみ状態のレイアウト

```
┌────┐
│ [▶]│  ← 開くボタンのみ
├────┤
│ 🎯 │  ← アイコンのみ表示
│ 🕐 │
└────┘
```

### 各要素の詳細

#### ヘッダー
- アプリ名テキスト（展開時のみ表示）
- 折りたたみトグルボタン（`◀` / `▶` で開閉を直感的に示す）

#### モード切替
- 「目標」「勤怠」の 2 項目
- アクティブ項目は背景色あり（サイドバーのアクセントカラー）
- 各項目の左にアイコン（目標: `🎯`、勤怠: `🕐`）

#### 年目標セクション（目標モード時のみ表示）
- セクションラベル「年目標」の右端に `[+]` ボタン
- `[+]` ボタンは 5 件追加済みの場合に **非活性（グレーアウト）**
- 各目標行:
  - 左に `▶` 三角アイコン（または小丸）
  - 目標タイトルテキスト（長い場合は省略）
  - ホバー時に右端に `…` メニューボタンが出現
  - `…` クリックで「削除」メニューが表示される

```

│  新しい年目標を追加します（最大5件）│

│  目標タイトル                    │
│  ┌──────────────────────────┐   │
│  │ 例: TOEIC 900点取得       │   │
│  └──────────────────────────┘   │
│                                  │
│              [キャンセル] [追加] │

```

## 削除確認ダイアログ

`…` → 削除 を選んだときに表示されるアラートダイアログ。

```
│  この操作は取り消せません。       │
│                                  │
│              [キャンセル] [削除] │
└─────────────────────────────────┘
```

## Pane 2〜4: Step 3 時点のプレースホルダー表示

Step 3 では Pane 2〜4 は **プレースホルダー**として表示する。

| Pane | 表示内容（プレースホルダー） |
|---|---|
| Pane 2 | 「Pane 2（実装予定）」テキスト、背景色: canvas |
| Pane 3 | 「Pane 3（実装予定）」テキスト、背景色: white/background |

## デザイントークン（カラー）

shadcn/ui の base-nova テーマを使用。モックアップでは以下の役割で色を指定してほしい。

| トークン名 | 役割 | 明るさのイメージ |
|---|---|---|
| `background` | メインコンテンツ背景（Pane 3） | 明るいベージュ系 |
| `canvas` | サブエリア背景（Pane 2, 4） | わずかに暗いベージュ |
| `sidebar` | Pane 1 の背景 | ベージュより少し濃い |
| `sidebar-foreground` | Pane 1 のテキスト | ダークグレー |
| `sidebar-accent` | Pane 1 のアクティブ項目背景 | ごく薄いグレー |
| `primary` | アクションボタン（追加・確定） | ネイビー系 |
| `muted-foreground` | プレースホルダーテキスト | ライトグレー |
| `border` | ペイン間の区切り線 | ごく薄いグレー |
| `destructive` | 削除ボタン | レッド系 |

## インタラクション仕様（モックアップで表現してほしいもの）

| 操作 | 期待する表示変化 |
|---|---|
| 「勤怠」クリック | Pane 4 が消え、3 ペイン表示になる |
| 「目標」クリック | Pane 4 が再表示され、4 ペイン表示に戻る |
| `[+]` クリック | 目標追加ダイアログが表示される |
| 目標行ホバー | `…` ボタンが右端に出現 |
| `…` クリック | 「削除」メニューが表示される |
| 「削除」クリック | 削除確認ダイアログが表示される |
| Pane 1 折りたたみ | アイコンのみの幅 48px に縮む |

## モックアップ依頼内容

以下の画面バリエーションを作成してほしい。

1. **目標モード・4ペイン展開状態**（Pane 1 展開 + 年目標 3 件表示）
2. **勤怠モード・3ペイン状態**（Pane 4 非表示）
3. **Pane 1 折りたたみ状態**（アイコンのみ）
4. **目標追加ダイアログ表示中**
5. **削除確認ダイアログ表示中**

ツールは何でも構いません（Figma / HTML / 画像 等）。
実装フェーズでコンポーネントを作る際の参考にするため、色・余白・フォントサイズ感が伝わるものを作成してください。
